# Contributing

Thanks for helping make this learning material accurate and practical.

- Write all study guides, quizzes, lab instructions, and code comments in English.
- Prefer independently authored examples, fictional incidents, small reproducible labs, and official technical references.
- Do not submit official certification questions, restricted course excerpts, personal notebooks, private URLs, credentials or confidential information.
- Add question rationales and distractors that demonstrate a specific technical misconception.
- Run `python -m pytest -q` and `mkdocs build --strict` before opening a pull request.
- Use clean Markdown compatible with the repository's `.markdownlint.json`.
- Contributions to code are made under MIT; contributions to original educational text under CC BY 4.0, unless otherwise agreed.
- This is an independent community project, not an official Anthropic course.
