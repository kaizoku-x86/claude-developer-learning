# Claude Developer Learning Hub

**Independent, community-authored study materials** for Claude development. This is not an official Anthropic course, and its practice questions are independently written.

!!! tip "Start here: How to Read This Course"
    New to the site? Read the [course guide](how-to-read.md) to see what each section contains, the recommended learning order, and how to combine reading, labs, and practice tests.

## Learning path

## Interactive practice

Choose [tests by module](tests/modules.md) for untimed practice or [full mock exams](tests/full-exams.md) for timed attempts matching the official exam's item counts. Short [topic drills](quizzes/index.md) are also available. No Claude API key is required.

## Hands-on labs

[Browse the laboratory guide](labs.md) for local exercises in API calls, agents, MCP, evaluations, prompt validation and security.
