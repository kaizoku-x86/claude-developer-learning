# Module 5 glossary — Accelerators and IP

Module-specific terminology based on [Accelerators and IP Contribution](05-accelerators-ip.md). These are study definitions, not an official certification glossary. See the [general glossary](00-general-glossary.md).

| Term | Definition |
|---|---|
| **Accelerator** | Reusable component, template, or workflow intended to speed up repeated implementation work. |
| **Reusable pattern** | A repeatable design or implementation approach that can be adapted to different tasks. |
| **Solution asset** | A reusable artifact such as a tool contract, starter template, test suite, or deployment guidance. |
| **Intellectual Property (IP)** | Legally protected creations and rights whose ownership and permitted reuse require review. |
| **Client-specific IP** | Deliverables or materials subject to a client's ownership, confidentiality, or contractual terms. |
| **License** | Terms specifying the conditions under which code, documents, and other materials may be used or redistributed. |
