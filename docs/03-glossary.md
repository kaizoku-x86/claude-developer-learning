# Module 3 glossary — Claude Code, MCP, and integrations

Module-specific terminology drawn from [Claude Code and MCP](03-claude-code-mcp.md) and [Claude products](03-claude-products.md). See the [general glossary](00-general-glossary.md) for cross-module terms.

| Term | Definition |
|---|---|
| **Claude Code** | A coding assistant and development workflow that can work with project context and tools. |
| **CLAUDE.md** | A file containing reusable project instructions and context for Claude Code; not a permissions system. |
| **MCP (Model Context Protocol)** | Protocol for connecting assistants and applications to external capabilities and context. |
| **MCP Tool** | An executable operation exposed through MCP. |
| **MCP Resource** | Information exposed for retrieval through MCP. |
| **MCP Prompt** | A reusable prompt template exposed through MCP. |
| **Stdio transport** | Process I/O transport for MCP messages; protocol traffic should not be mixed with arbitrary stdout logs. |
| **Claude Projects** | Shared project instructions and knowledge for conversations in the product. |
| **Artifacts** | Generated deliverables and supported interactive artifacts. |
| **Connectors** | Integrations to external applications and data, subject to permissions. |
