# Claude products — quick reference

**Source:** learner notes in `Glosary.docx`.

- **Claude Projects:** reusable instructions and knowledge shared across related conversations in a project.
- **Artifacts:** generated deliverables and certain interactive prototypes. The original notes misspelled this as "Artificats".
- **Connectors:** integrations that grant permission-controlled access to external data and tools.

## Key distinctions

Projects manage shared context; Artifacts support creating and iterating on deliverables; Connectors connect the product to external information and tools. None is, by itself, an authorization mechanism.
