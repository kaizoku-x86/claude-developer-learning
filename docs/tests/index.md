# Tests and Exam Practice

Prepare using two complementary styles of assessment. All questions are **independently authored**; they are not official Anthropic exam items.

## Choose your practice mode

| Mode | Questions | Time limit | When to use it |
|---|---|---|---|
| [Tests by Module](modules.md) | Varies by course module | None | Review what you learned and inspect the rationale for missed questions |
| [Full Mock Exams](full-exams.md) | **53** or **70**, depending on the official CCDV-F version | **120 minutes** | Rehearse pacing, navigate between items, and practice under time pressure |
| [Short Topic Drills](../quizzes/index.md) | A few focused questions per topic | None | Check one skill without attempting a full module |

## Exam version matters

The [official CCDV-F exam guide (effective November 2026)](https://cc.sj-cdn.net/instructor/6nizmqk8tpzpfjvt6qmmav7rh/public/1794946716/Claude_Certified_Developer_-_Foundations_Exam_Guide.pdf) specifies **53 questions in 120 minutes**. The [updated guide effective 7 December 2026](https://cc.sj-cdn.net/instructor/6nizmqk8tpzpfjvt6qmmav7rh/public/1794946771/Claude_Certified_Developer_-_Foundations_Exam_Guide_Updated_Dec_7.pdf) specifies **70 questions in 120 minutes**; 60 are scored and 10 are unscored in the official exam.

Our practice tests score **all** practice questions. A percentage here is **not** the official scaled certification score and must not be interpreted as a pass or fail determination. The practice questions are assigned approximate official domain proportions, but their difficulty has not been psychometrically validated.

## Privacy and technical requirements

- No sign-in, API key, or backend is required.
- Responses, flagged items and the timer deadline are saved in **local browser storage**. A refresh does not reset an active full-exam timer.
- A full exam is submitted automatically if the time limit expires.
- Quiz data and answer keys are available in the open-source site, so these are **self-study tools**, not secure proctored examinations.
