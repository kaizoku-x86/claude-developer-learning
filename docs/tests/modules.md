# Tests by Module

Use these **untimed** tests after reading the corresponding study guides. Questions are grouped by the course's five learning modules, not by the eight official exam domains.

You can move between questions, flag uncertain answers, and review explanations after submitting. The questions are presented in a different order on each new attempt.

!!! tip "Suggested workflow"
    Read the module, complete one or more [labs](../labs.md), then try the module test. Inspect missed questions and return to the relevant [study guide](../how-to-read.md).

For shorter exercises, visit the [topic drills](../quizzes/index.md). For a timed assessment, open [Full Mock Exams](full-exams.md).
